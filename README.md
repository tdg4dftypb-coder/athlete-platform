# Athlete Platform

Personal AI platform for endurance training, health and recovery.

## Vision

Athlete Platform is a personal data platform that collects information from multiple sources:

- Intervals.icu
- Apple Health
- Body Composition
- Blood Tests
- Blood Donations

The goal is not to build another dashboard.

The goal is to build an AI Coach that understands long-term trends and provides actionable recommendations.
